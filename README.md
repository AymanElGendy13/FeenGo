# FeenGo

Book any place, for any occasion. A marketplace app for Egypt that connects people with restaurants, cafes and venues, for everyday table bookings and for celebrations.

Three products share one backend:

- **Customer app** for iPhone and Android, in Flutter
- **Partner dashboard** for venues, in Next.js
- **Admin back office**, in Next.js

Start with `docs/ROADMAP.md` to see what is being built now, and `CLAUDE.md` for how work is done in this repository.
